## Interpretation

This shows the previous factual-target normalization still failed in some low-yield years. Example: wheat 2020 has `0.578 t/ha` in `productivity_data`, but current target has `5.780 t/ha`. The old rule divided by 10 only when the value exceeded a crop-specific cap, so low catastrophic yields in `ц/га` were not corrected.

Next: build v12 by overriding exact-matched current targets with `productivity_data` fact values converted from `ц/га` to `t/ha`.
