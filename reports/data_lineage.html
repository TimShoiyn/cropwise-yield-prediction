Входные данные для модели урожайности

Сырые входные данные (raw)

Файл Где используется Содержание (кратко)
data_raw/fields.csv build_ml_dataset.py, compare_by_crops_and_cropwise.py Справочник полей: id, название, геометрия, площади, координаты
data_raw/crops.csv build_ml_dataset.py, compare_by_crops_and_cropwise.py Справочник культур: id, название (для маппинга crop_id)
data_raw/productivity_estimates.csv build_ml_dataset.py Основной источник таргета: field_id, year, estimate_value → target_yield_t_ha
data_raw/additional_yields_from_history.csv build_ml_dataset.py Дополнительные значения урожайности (добавляются только для новых (field_id, year))
data_raw/yield_maps.csv build_ml_dataset.py Карты урожайности; доп. источник таргета для новых (field_id, year) (avg по карте)
data_raw/history_items_full.csv build_ml_dataset.py История культур по полю/году: используется для crop_id и prev_crop_id
data_raw/ndvi_timeseries.csv build_ml_dataset.py Временные ряды NDVI по полям и датам
data_raw/soil_tests.csv build_ml_dataset.py Почвенные показатели (pH, OM, P, K, N, Mg, CEC и др.) по полям
data_raw/weather_season_aggregates.csv build_ml_dataset.py Сезонные агрегаты погоды по (field_id, year): температуры, осадки, снег
data_raw/operations.csv build_ml_dataset.py Агрооперации: агрегаты ops_* (типы работ, даты посева/уборки, NPK из application_mix_items) и поднабор ops_ndvi_2021_2025
data_raw/fertilizers_npk.csv build_ml_dataset.py (опционально) Справочник состава удобрений: id, N, P2O5, K2O (для более точного расчёта ops_npk_*)
data_raw/seeds.csv build_ml_dataset.py (опционально) Каталог семян: используется для восстановления crop_id через seed_id → crop_id (если файл присутствует)
data_raw/productivity_data.csv compare_by_crops_and_cropwise.py Экспорт «Cropwise productivity»; столбец «прогноз» численно совпадает с таргетом

Raw файлы, которые лежат в data_raw/, но не участвуют в текущей сборке датасета

Эти файлы сохранены “про запас”, но в текущем пайплайне (сборка ml_dataset_full_extended.csv + обучение/оценка) не используются: plant_threats.csv, field_scout_reports_aggregated.csv, growth_stage_groups.csv, growth_stages.csv, growth_scales.csv, productivity_estimate_peers.csv, productivity_estimate_histories.csv, weather_history_items.csv, soil_test_samples.csv, field_to_station_mapping.csv, weather_stations.csv.

Схема входных таблиц (ключи и важные поля)

Источник Гранулярность Ключ(и) Важные поля (пример)
data_raw/fields.csv поле id id, name, field_tillable_area, field_calculated_area, field_lat, field_long, (геометрия/контур)
data_raw/crops.csv справочник id id, name
data_raw/ndvi_timeseries.csv поле–дата field_id, date field_id, date, ndvi
data_raw/weather_season_aggregates.csv поле–год field_id, year temp_*, precip_*, snow_* (сезонные агрегаты)
data_raw/soil_tests.csv поле–дата теста field_id, made_at soil_pH.value, soil_organic_matter.value, soil_P.value, soil_K.value, soil_N.value/soil_N_NO3.value, soil_Mg.value, soil_cation_exchange_capacity.value, soil_Ca_saturation.value
data_raw/operations.csv операция field_id, performed_at (и др.) типы работ (soil/application/harvesting/…), даты, нормы и NPK (если есть)

Примечание: operations.csv и признаки ops_* используются только в отдельной подвыборке ops_ndvi_2021_2025 и не являются основой финальной модели.

data_processed/ml_dataset_ndvi_only_extended.csv build_ml_dataset.py Датасет с расширенными NDVI‑признаками + культура/геометрия (+ часть метео/почвы)
