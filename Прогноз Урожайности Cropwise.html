Исходная проблема (Deep Review Report)

Обнаруженные методологические ошибки:

  • In-sample метрики по культурам (R²≈0.99) вместо OOF-валидации
  • Утечка данных через импутацию вне Pipeline и harvest-фичи
  • «Прогноз Cropwise» (R²=1.0, RMSE=0) — дубликат таргета из productivity_data.csv

План исправлений: Итерация 1 (устранение утечек, OOF-валидация) → Итерация 2 (регуляризация, выбор алгоритма)

Итерация 1: Устранение методологических ошибок

Изменения в коде:

  • train_baseline_model.py: Импутация в Pipeline (ColumnTransformer + SimpleImputer с add_indicator=True), удалены harvest-фичи
  • evaluate_with_oof(): GroupKFold по годам → OOF-предсказания без утечки
  • compare_by_crops_and_cropwise.py: Метрики по культурам на OOF, проверка дубликата Cropwise

Результат: Все метрики (CV и по культурам) теперь считаются на OOF через GroupKFold по годам

Итерация 2: Регуляризация и выбор алгоритма

Grid search GBDT + сравнение с CatBoost:

Сетка GBDT:

  • max_depth ∈ {2, 3, 4}
  • min_samples_leaf ∈ {5, 10, 20}
  • subsample ∈ {0.7, 0.8, 1.0}
  • learning_rate ∈ {0.05, 0.1}
  • n_estimators ∈ {100–300}

Лучший GBDT:

  • depth=3, min_leaf=5
  • subsample=0.7, lr=0.05
  • n_estimators=300
  • CV R²=0.37 (↑ с 0.25)

CatBoost: CV R²=0.30, MAPE=18.4% → не превзошёл регуляризованный GBDT
